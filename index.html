Concept Gap

Root Cause: เข้าใจสูตร “เปอร์เซ็นต์ของพื้นที่” คลาดเคลื่อน — ตีความ 60% ผิดเป็นสัดส่วนของเส้นรอบรูปแทนที่จะเป็นพื้นที่ทั้งหมด (Misconception)

AI Interventionทบทวน Concept เปอร์เซ็นต์กับพื้นที่ผ่าน Micro-lesson 5 นาที + โจทย์ฝึกแบบ Visual ก่อนกลับไปทำ Mission ต่อ

Tan K. — Learning DNA

Application Gap

Root Cause: เข้าใจเปอร์เซ็นต์ดี แต่สับสนลำดับขั้นตอนเมื่อโจทย์มีหลายเงื่อนไขต่อกัน (งบประมาณ + พื้นที่ + ส่วนที่เหลือ) — Application Gap ไม่ใช่ Concept Gap

AI Interventionเพิ่ม Mission แบบ Multi-step Real-world Problem พร้อม Worked Example ทีละขั้น เพื่อฝึกลำดับการแก้โจทย์ซับซ้อน

Pitch Script — 3 Minutes

Pitch Script · สคริปต์นำเสนอ

0:00–0:25
Hook
ถ้านักเรียนสองคนได้คะแนนเท่ากัน 6 เต็ม 10 เราจะสรุปได้ไหมว่าเขาเรียนรู้เหมือนกัน? คำตอบคือไม่ คนหนึ่งอาจจำ Concept ได้แต่ประยุกต์ใช้ไม่ได้ อีกคนอาจ Concept ยังไม่แม่นแต่มีทักษะการคิดวิเคราะห์ที่ดี แต่ในห้องเรียนทั้งสองคนอาจถูกมองว่าเป็นเพียง "เด็กที่ได้ 6 คะแนน" เหมือนกัน
0:25–0:50
Problem
ครูในห้องเรียนต้องดูแลนักเรียนจำนวนมาก และข้อมูลที่มีมักบอกเพียงผลลัพธ์ เช่น คะแนนหรือข้อถูกผิด แต่สิ่งที่หายไปคือกระบวนการเรียนรู้ เราจึงตั้งคำถามว่า ถ้าเราไม่ได้แค่รู้ว่าเด็กตอบผิด แต่รู้ว่าเขาผิดเพราะอะไร จะเกิดอะไรขึ้น?
0:50–1:20
Solution
นี่คือ EduTwin — AI Learning Twin ระบบที่สร้าง Digital Twin ของการเรียนรู้ของนักเรียน EduTwin วิเคราะห์ทั้งคำตอบ วิธีคิด การขอ Hint การอธิบายเหตุผล และกิจกรรมที่นักเรียนทำ แล้วเปลี่ยนข้อมูลเหล่านี้เป็น Learning DNA เพื่อให้เราเห็นว่าเด็กเก่งอะไร ติดตรงไหน และควรพัฒนาอย่างไร
1:20–1:50
Killer Feature
สิ่งที่แตกต่างที่สุดคือ Mistake DNA เพราะ EduTwin ไม่ได้บอกแค่ว่าข้อนี้ผิด แต่บอกว่าผิดเพราะ Concept Gap, อ่านโจทย์ หรือไม่สามารถนำความรู้ไปประยุกต์ใช้ จากนั้น AI จะสร้าง Learning Path ที่เหมาะกับนักเรียนแต่ละคน
1:50–2:15
Teacher
สำหรับครู EduTwin เปลี่ยนข้อมูลของนักเรียนเป็น Teacher Copilot ครูเห็นได้ทันทีว่าใครต้องทบทวน ใครต้องฝึกเพิ่ม และใครพร้อมสำหรับ Challenge AI ยังช่วยจัดกลุ่มนักเรียนและแนะนำกิจกรรมที่เหมาะสม
